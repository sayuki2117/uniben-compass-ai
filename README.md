# UNIBEN Compass AI

A modern AI chatbot web application for University of Benin prospective students, admitted students, staff, and public inquiries.

## Tech Stack

- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: FastAPI, Python 3.11, OpenAI/OpenRouter, Supabase
- Database: Supabase Postgres with pgvector for RAG

## Local Ports

- Frontend: http://localhost:3005
- Backend: http://localhost:8005
- Backend API docs: http://localhost:8005/docs

## Setup Order

1. Create and configure Supabase.
2. Set up backend `.venv` and `.env`.
3. Run the backend.
4. Set up frontend `.env.local`.
5. Run the frontend.
6. Ingest knowledge base files.
7. Test the chatbot.

Full step-by-step instructions are in the backend and frontend README files.
