# Frontend Setup

## 1. Open Git Bash

```bash
cd ~/Desktop/FULL-STACK-AI/uniben-compass-ai/frontend
```

## 2. Install Dependencies

```bash
npm install
```

## 3. Create Environment File

```bash
cp .env.local.example .env.local
```

Keep:

```env
NEXT_PUBLIC_API_URL=http://localhost:8005
```

## 4. Run Frontend

```bash
npm run dev
```

Open:

```text
http://localhost:3005
```
